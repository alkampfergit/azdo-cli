# 0.14.0 — 2026-06-26

> Maintainer skill for release-maintenance automation; type-safe generic markdown code spans (ADO sanitizer fix); hardened dev dependency chain.

### Added
- **Maintainer skill** — `.agents/skills/maintainer/` codifies release maintenance workflows for the `maintainer` skill.

### Fixed
- **Generic type args preserved in markdown code spans** — ADO's REST API sanitizer strips `<T>` inside backtick spans as unknown HTML tags. Pre-escape `<`/`>` as `&lt;`/`&gt;` before upload; decode back on the plain-text download path, with an HTML safety net for web-UI-stored fields. Also fixes `addWorkItemRelation` idempotency: relation URLs returned by ADO include a project GUID segment the constructed URL omitted, so the duplicate check always failed — now uses `parseTargetId()` consistently with `removeWorkItemRelation`. (#74/#75)

### Security
- **Bump vulnerable dev dependencies** — vite 8.0.3 → 8.0.16 (GHSA-fx2h-pf6j-xcff high, GHSA-v6wh-96g9-6wx3 medium), postcss 8.5.8 → 8.5.10 (GHSA-qx2v-qp2m-jg93 medium), esbuild 0.27.3 → 0.28.1 via overrides (GHSA-g7r4-m6w7-qqqr low). All dev-only transitive deps; `npm audit` reports zero vulnerabilities. (#73)
