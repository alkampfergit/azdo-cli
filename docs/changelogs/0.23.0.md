# 0.23.0 — credential-store diagnostics

> Credential-store errors now expose the underlying cause, with clearer Linux guidance when Secret Service is unreachable.

### Changed

- `CredentialStoreUnavailableError` now appends a redacted `Underlying error:` detail when the keyring library provides a cause. On Linux, the guidance explains that Secret Service may be missing or unreachable—for example, when a sandbox or container blocks the user D-Bus socket—and points to `AZDO_PAT` as a keyring bypass. Behavior and exit codes are unchanged. (#155)

### Documentation and tests

- Document the troubleshooting detail in `docs/authentication.md` and `docs/linux-credential-store.md`.
- Add unit coverage for cause rendering, token-shaped text redaction, and Linux troubleshooting guidance.
