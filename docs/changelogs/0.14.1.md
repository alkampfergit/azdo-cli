# 0.14.1 — 2026-06-26

> Patch: ADO HTML-entity decoding for non-HTML markdown field downloads.

### Fixed
- **Decode ADO HTML entities in non-HTML markdown fields** — Azure DevOps HTML-encodes certain characters in stored markdown fields (`>` blockquote markers → `&gt;`, em dashes → `&mdash;` / `&#8212;`). `toMarkdown()` now decodes the full HTML4 named-entity set plus all numeric entities (decimal and hex) before returning plain-text output; `&amp;` is decoded last to preserve intentional literal entity strings. Also strips ADO's trailing newline before appending the CLI's own newline, making set/get roundtrips byte-identical. Adds Windows/PowerShell UTF-8 encoding note to `get-md-field` docs. (#76/#77)
