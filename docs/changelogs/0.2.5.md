# 0.2.5 — 2026-03-09

> The first working CLI. Consolidates the same-day `0.2.0`–`0.2.5` prerelease
> series: the commander.js CLI scaffold, the first work-item commands
> (`001-azdo-cli-base`, `002-get-item-command`), settings (`003-cli-settings`),
> work-item updates (`004-update-work-item`), markdown field commands
> (`005-md-field-commands`), and the CI/publish pipeline.

### Added

- **CLI foundation** — commander.js entry point, `--version`/`-v`, and no-argument help behaviour (T001–T013, `001-azdo-cli-base`).
- **`get-item` command** — retrieve a work item by ID with explicit org/project or git-remote auto-detection (`002-get-item-command`).
- **CLI settings** — set/view default organization and project, persisted to `~/.azdo/config.json` (`003-cli-settings`).
- **Update work item** — change state and assign work items (`004-update-work-item`, #4).
- **Markdown field commands** — get/set markdown (multiline rich-text) fields (`005-md-field-commands`, #5).
- **CI/CD pipeline** — GitHub Actions workflow with unit tests, npm publish via OIDC trusted publishing, and GitHub Release step (T018–T024); GitVersion-style prerelease tags.

### Changed

- **API URL handling** — encode Azure DevOps API URLs and field-value URLs to handle special characters (#7).

### Fixed

- **PAT validation** — corrected personal access token validation.
- **Field configuration** — fixed handling of multiple field config/parameters.
