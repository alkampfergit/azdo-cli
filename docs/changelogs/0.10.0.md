# 0.10.0 — 2026-04-24

> The authentication and PR-collaboration release: secure multi-org PAT
> storage with a dedicated `auth` command, reliable PR comment threads with
> resolve/reopen, and a hardened PAT entry flow.

### Added

- **`auth` command & secure PAT storage** — first-time interactive setup with secure, OS-backed multi-org credential storage (one PAT per org), `auth` / `auth status` / `auth logout`, browser-assisted PAT creation, hybrid org resolution (`--org` / git remote / config), and an audit log (`016-pat-secure-storage`, #33).
- **PR comment threads** — list comment threads on the current branch's PR without crashing, plus `--pr-number`, `--hide-resolved`, and `comment-resolve` / `comment-reopen` subcommands (`017-pr-comments-threads`, #34).

### Fixed

- **PAT input visibility** — prevent raw PAT characters from appearing during paste/input; readline output suppressed during entry (`015-fix-pat-visibility`).

### Changed

- **Tolerant `_links` and libuv-safe exit** in PR comment handling (#34).
- **Repository tooling** — restructured and added automation skills (`fixer`, `gitflow`) wired into the speckit flow.
