# 0.3.0 — 2026-03-26

> Richer markdown handling: automatic markdown rendering of rich-text fields,
> and upserting work items from markdown documents.

### Added

- **Auto markdown display** — configurable automatic markdown rendering of rich-text fields, with a per-command toggle (`006-auto-md-display`, #10).
- **Work item upsert from markdown** — create or update work items (tasks) from a markdown document (`007-work-item-upsert`, #12).

### Changed

- Refreshed npm dependencies.
